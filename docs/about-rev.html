About This Site

This portfolio was designed and hand-coded by me using
Quarto, HTML, CSS/SCSS, and R. No drag-and-drop builders involved!

See how it all came together:
https://github.com/kathleen-juarez/portfolio-site.git

NoteWhat’s GitHub?

GitHub is a website where people store and share code. Think of it like Google Drive, but specifically designed for software projects. It lets developers save their work, track changes over time, and collaborate with others without overwriting each other’s work.

If you’re asking yourself this question, you’ve clearly never spent the night crying in front of your computer after unsuccessfully trying to push your code to GitHub, merge divergent branches, and then lose your entire document in the process. Ah, to have a layman’s innocence.

What went into it

  • Design — layout, color palette, and typography decisions made from scratch
  • Structure — built with Quarto’s publishing framework, configured for GitHub Pages hosting
  • Styling — custom CSS/SCSS architecture: global styles, hero-specific styles, and per-page stylesheets
  • Debugging — a lot of it (see below)

Tools Used
